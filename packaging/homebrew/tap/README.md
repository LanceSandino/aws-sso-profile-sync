# Homebrew tap bootstrap files

The public shared tap is maintained in
[LanceSandino/homebrew-tap](https://github.com/LanceSandino/homebrew-tap).
Its README lists every available formula and installation commands.
AWS SSO Profile Sync 2.0.1 is published and installable:

```sh
brew install LanceSandino/tap/aws-sso-profile-sync
```

This directory contains the original bootstrap files used to create that separate
repository. It is not the live tap and has no installable formula. Its workflows
and verifier are historical starting points; use the standalone repository's
current files and source pins for maintenance. Do not copy this snapshot over the
live tap's later fixes. See [formula generation](../README.md).
